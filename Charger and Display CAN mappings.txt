 SLAVE 2 : SOLTERRA CHARGER
────────────────────────────────────────────────────────────────────────────

  ID 0x1806E5F4  BMS -> Charger  (Charge command)  TX every 1 s   [8 bytes]
    Byte  Field           Type   Scale     Notes
    0-1   V_setpoint      u16 BE  x0.1 V    (v_raw = V*10, big-endian: [MSB,LSB])
    2-3   I_setpoint      u16 BE  x0.1 A    (i_raw = I*10, big-endian: [MSB,LSB])
    4     ctrl            u8      -         0x00=START(enabled) 0x01=STOP
    5-7   reserved        --      -         0x00 0x00 0x00

    Auto-stop/timeout frame (sent once on 5s comm timeout):
      [Vhi, Vlo, 0x00, 0x00, 0x01, 0x00, 0x00, 0x00]   (I forced to 0, ctrl=STOP)

  ID 0x18FF50E5  Charger -> BMS  (Broadcast status)   RX, dlc >= 5  [>=5 bytes]
    Byte  Field           Type   Scale     Notes
    0-1   actual_V        u16 BE  x0.1 V
    2-3   actual_I        u16 BE  x0.1 A
    4     flags           u8      -         bitmask, see below

    flags bitmask:
      bit0 (0x01)  HW Fail
      bit1 (0x02)  Over Temp
      bit2 (0x04)  Input Err
      bit3 (0x08)  INHIBIT
      bit4 (0x10)  Comm Err
    Fault group = bit0|bit1|bit2 (0x07) -> forces state = FAULT

────────────────────────────────────────────────────────────────────────────
 CHARGER STATE MACHINE (derived, not on the wire)
────────────────────────────────────────────────────────────────────────────
  DISCONNECTED -> READY -> CHARGING -> (FAULT | INHIBITED | TIMEOUT)

  eval order:
    flags & 0x07        -> FAULT
    elif flags & 0x08   -> INHIBITED
    elif V>0 and I>0    -> CHARGING
    else                -> READY
  TIMEOUT: no RX broadcast for > 5.0 s (COMM_TIMEOUT_S)
